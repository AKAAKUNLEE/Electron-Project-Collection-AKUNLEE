# Doubao Desktop

## 项目介绍
这是 doubao.com 的桌面应用版本，基于 Electron 开发，提供了更便捷的桌面使用体验。该应用支持登录状态持久化，确保您的登录信息在应用重启后仍然保持。

### 当前版本
**V1.0.1**

## 功能特性
- ✅ 完整访问 doubao.com 网站功能
- ✅ 登录状态持久化
- ✅ 跨平台支持（Windows、macOS）
- ✅ 优化的窗口配置，提供良好的用户体验
- ✅ 快速启动和加载

## 安装和运行

### 安装依赖
```bash
npm install
```

### 运行开发版本
```bash
npm start
```

### 构建发布版本
```bash
npm run build
```
构建后的可执行文件将位于 `doubao-desktop-1.0.0` 目录中。

## 项目结构
```
doubao-desktop/
├── main.js          # 主进程文件，负责窗口管理和会话持久化
├── preload.js       # 预加载脚本，向渲染进程暴露必要的 API
├── index.html       # 应用启动页面
├── package.json     # 项目配置
├── README.md        # 项目文档
└── doubao-desktop-1.0.0/  # 构建输出目录
```

## 技术栈

## 使用说明
1. 运行应用后，将会自动加载 doubao.com 网站
2. 在网站上进行登录操作，登录状态将会被持久化
3. 关闭并重新打开应用后，您的登录状态仍然保持
4. 您可以像在浏览器中一样使用 doubao.com 的所有功能

## 登录状态持久化
应用使用 Electron 的会话管理功能来持久化登录状态，确保您的登录信息在应用重启后仍然有效。这意味着您只需要登录一次，就可以在后续使用中保持登录状态。
