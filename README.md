# Fanqienovel作家助手

## 项目介绍
Fanqienovel作家助手是一个基于Electron技术开发的桌面应用程序，专为番茄小说网作家专区设计，提供便捷的章节管理和写作辅助功能。

### 当前版本
**V1.0.1**

## 功能特性
- ✅ 完整访问番茄小说作家专区
- ✅ 自动保存登录状态，无需重复登录
- ✅ 会话持久化，应用重启后保持登录状态
- ✅ 优化的窗口大小和用户体验
- ✅ 跨平台支持（Windows、macOS）

## 安装和运行

### 安装依赖
```bash
npm install
```

### 运行开发版本
```bash
npm start
```

### 构建发布版本
```bash
npm run build
```
构建后的可执行文件将位于 `dist` 目录中。

## 项目结构
```
fanqienovel-app/
├── main.js          # 主进程文件
├── preload.js       # 预加载脚本
├── package.json     # 项目配置
├── README.md        # 项目文档
└── dist/            # 构建输出目录
```

## 技术栈
- Electron ^40.1.0
- Node.js
- JavaScript

## 登录数据保存机制
应用使用Electron的内置会话管理系统来保存登录状态：
- 自动存储cookies和会话信息
- 应用重启后保持登录状态
- 安全的cookie策略配置
- 会话数据持久化存储

## 注意事项
- 首次使用时需要手动登录番茄小说账号
- 登录状态会自动保存，后续打开应用无需重新登录
- 如遇到登录状态丢失，请尝试重新登录
